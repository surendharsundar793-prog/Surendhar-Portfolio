## ⚙️ Setup & Local Installation

### Prerequisites

* Ensure [Node.js](https://nodejs.org/) (v18 or higher) is installed.

### 1. Navigate to Project
Open your terminal in the portfolio folder directory:
```bash
cd Portfolio
```

### 2. Install Packages
Install dependencies:
```bash
npm install
```

### 3. Setup Env Key
Create a `.env` file in the root directory and add your Web3Forms access key for the contact form:
```env
VITE_WEB3FORMS_ACCESS_KEY=your-key-here
```

### 4. Run Locally
Start the development server:
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 5. Build for Production
Create an optimized production bundle:
```bash
npm run build
```
The built files will be output to the `/dist` directory.
